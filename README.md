# 🍽️ Smart Restaurant Kiosk & Management System

A modern web-based restaurant kiosk and management system built using **Flask, SQLite, HTML, CSS, and JavaScript**.  
This project is designed for **Quick Service Restaurants (QSRs)** such as cafés, food courts, and fast-food chains where customers can place orders independently through a self-service kiosk.

---

# 🚀 Features

## 👨‍🍳 Customer Kiosk
- Browse categorized menu items
- Add/remove items from cart
- Dine-In & Takeaway options
- Place orders without login
- Order confirmation with unique Order ID
- Track order status in real time

---

## 🔔 Real-Time Notifications
- Popup notifications when order is ready
- Voice announcements using browser speech synthesis
- Dynamic status updates without page reload

---

## 🍳 Chef Dashboard
- Live incoming orders
- Separate Pending & Completed sections
- One-click “Mark Ready” functionality
- Automatic order status synchronization

---

## 🛠️ Admin Panel
- Add/Edit/Delete menu items
- Upload item images
- Manage categories and prices
- View complete order details

---

## ⚡ Dynamic Updates
- AJAX/Fetch API based polling
- Real-time-like updates
- Smooth user experience without full page refresh

---

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd your-repo-name
```

---

## 3️⃣ Install Dependencies

```bash
pip install flask
```

---

## 4️⃣ Run the Application

```bash
python app.py
```

---

## 5️⃣ Open in Browser

```bash
http://127.0.0.1:5000
```
